# Metrics Dictionary

## Product Metrics

| Metric | Definition | Why It Matters |
|---|---|---|
| Image Upload Completion Rate | Percentage of users who uploaded image after image request | Measures completion of proof collection step |
| Abandonment After Image Request | Users who abandon after image request | Measures journey friction |
| Bot Containment Rate | Sessions resolved without human agent | Measures automation success |
| Escalation Rate | Sessions sent to human agent | Measures bot failure or fallback usage |

## GenAI Metrics

| Metric | Definition | Why It Matters |
|---|---|---|
| Correct Intent but Failed Continuation | Bot understood issue but user failed next step | Shows journey failure after AI understanding |
| Image Analysis Failure Rate | Uploaded images that AI could not analyze | Measures vision model weakness |
| Repeated Prompt Rate | Bot asks same thing again after user action | Measures conversation loop failure |
| Groundedness | Bot response matches actual system state | Prevents false or unsupported responses |

## Business Metrics

| Metric | Definition | Why It Matters |
|---|---|---|
| Lost Automation Opportunity | Cases bot could have resolved but did not | Shows missed cost-saving opportunity |
| Agent Cost | Cost due to escalation | Shows operational impact |
| Repeat Contact Risk | Chance user contacts again after poor resolution | Shows customer experience risk |
